# IoT

This category covers all IoT devices in the homelab: sensors, smart plugs, and the MQTT broker integration.

All IoT devices are isolated on **VLAN 30** (10.136.30.0/24) and communicate with `weathertop.shire` (Home Assistant OS) via MQTT.
